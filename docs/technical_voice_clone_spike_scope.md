# 私有声音复刻技术闭环范围

## 当前用户目标

给定一段已获授权的视频和一段中文文本，程序能够从视频提取参考人声，并生成以该参考声音朗读指定文本的可播放音频。

## 来源

- 用户在 2026-08-21 的直接要求。
- `nashide_ta_private_voice_wechat_mvp_prd_v0.4.md` 的 11、12、13、14、24.2、24.5、25.1 和 M1 章节。

## P0 验收要求

### TVC-001 视频输入与参考音频

- 接受本地视频路径。
- 使用 FFprobe 验证媒体可解码。
- 使用 FFmpeg 提取单声道、24kHz、16-bit WAV。
- 支持选择开始时间和 10–30 秒片段；默认选择不超过 20 秒的片段。
- 输出基础质量报告：时长、平均音量、静音比例、削波比例。

### TVC-002 授权门禁

- 未显式确认拥有声音复刻和合成权限时拒绝执行。
- 结果清单标记输出为 AI 生成。
- 默认删除临时参考音频。

### TVC-003 零样本声音复刻

- 使用可替换的 `VoiceProvider` 接口。
- 本地默认实现为 Chatterbox Multilingual，支持中文与 CPU。
- 指定中文文本后生成非空、可解码的 WAV 文件。

### TVC-004 可复现入口与证据

- 提供单条 CLI 命令执行完整链路。
- 生成与音频同名的 JSON 清单，包含引擎、模型、片段参数、质量报告、哈希和状态，不保存输入文本明文。
- 自动化测试使用假 Provider 覆盖视频到输出音频的完整控制流。
- 真实模型验收必须使用用户提供且已获授权的视频；未提供样本时不能宣称真实声音相似度通过。

## 本轮明确不做

- 微信小程序页面、登录、支付、额度、对象存储和 PostgreSQL。
- LLM 对话、内容安全供应商和长期记忆。
- 公网部署、商用上线、供应商备案与算法材料。
- 多说话人自动分离、自动转写、音色永久托管。
- 声音相似度的纯自动结论；最终主观相似度由用户听辨。

## 最终判定

- 自动化控制流、媒体质量和结果可解码通过，但缺少用户授权视频或用户听辨：`PASS_WITH_LIMITATION`。
- 用户授权视频真实生成成功，且用户确认声音可接受：`PASS`。
