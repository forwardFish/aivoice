## 输出说明

- `*_复刻试听.wav`：三个年龄使用完全相同的测试台词，适合横向比较音色。
- `*_角色试听.wav`：按年龄分别设计的不同台词，适合判断角色表现。
- `同台词连播_3-8-12岁.wav`：顺序为 3 岁 → 8 岁 → 12 岁。
- `角色台词连播_3-8-12岁.wav`：顺序为 3 岁 → 8 岁 → 12 岁。
- `*.reference.wav`：实际用于复刻的敏感参考音频，应按授权和隐私策略保管。
- `*.manifest.json`：生成参数、参考质量报告、校验值和供应商信息。

所有合成音频均为 AI 生成内容。技术质量检查通过不等于音色相似度或角色听感通过，最终以授权方人工试听验收为准。
