| 年龄 | 授权源视频 | 正式试听 |

## 每个年龄目录

- `reference.wav`：实际用于复刻的授权参考音频，是敏感声音资产和音色重建依据。
- `preview.wav`：该音色生成的新台词试听。
- `direct-compare.mp3`：参考声音 → 1 秒静音 → AI 生成声音。

## 阿里云音色映射

三个音色均绑定 `cosyvoice-v3.5-flash`。可继续调用的供应商音色 ID 保存于 `private/provider-voice-registry.dpapi.json`，使用 Windows DPAPI CurrentUser 加密，只能由当前 Windows 用户解密。明文 ID 没有写入普通文档。

如果供应商音色过期或被删除，可依据每个年龄的 `reference.wav` 重新创建；`manifest.json` 保存了来源、文本、模型和 SHA-256 校验值。

## 安全与授权

用户已在本任务中确认这些源视频已取得声音本人及未成年人监护人对 AI 音色复刻和短视频使用的授权。项目仍应单独保存可追溯的书面授权文件。

`reference.wav` 与 `private/` 已通过本目录 `.gitignore` 防止误提交，但仍保存在本机工作区。所有合成音频均应标注为 AI 生成。
