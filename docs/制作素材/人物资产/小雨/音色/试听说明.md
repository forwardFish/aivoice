# 小雨原创成长音色试听

本目录音频为 AI 生成的原创虚构音色，不对应任何真实儿童。

## 试听顺序

每个候选目录中的 `三年龄连播_3-8-12岁.wav` 按以下顺序播放：

1. 3 岁
2. 8 岁
3. 12 岁

相邻年龄之间有约 0.7 秒静音。

三段均使用同一个候选音色 ID 和同一句测试台词，只改变年龄化表达指令，用于判断是否像“同一个女孩逐渐长大”。

## 建议

- 优先试听候选 A 和候选 B；客观基频变化比候选 C 更符合低龄偏高、成长后偏低的方向。
- 先判断基础音色是否符合“小雨”，再判断三个年龄是否保持同一人感。
- 当前文件是选角试听资产，不是最终剧情台词成品。

## 测试台词

> 妈妈，你看，窗外那朵云像不像一只小兔子？我想把今天记下来，等长大以后再听。
